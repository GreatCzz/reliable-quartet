# 放置增量 Δ 的数学验证（probe）

## 结论（已在 20 组随机用例上与暴力一致）

对物种树 T、新类群 x、插入边 e_p 的内部点 q：

```
Δ(p) = Σ_{三元组 {a,b,c} ⊆ leaves(T)} Σ_g  1[ (x,L) 与 (M,N) 在 g 中都是实线对 ]
```

其中：
- `m` = {a,b,c} 在 T 中的**中位数**（三个两两 LCA 中最深的那个）；
- 删掉 m 后 T 分成三个分量，分别含 a、b、c；
- **L** = 其所在分量包含 q 的那个叶子（就是"x 落在谁的扇区里"）；
- `{M,N}` = 另外两个叶子。

直觉：x 挂在 q 点，诱导出的四叶树分裂是 `(x,L) | (M,N)`；若 q 恰好落在 m 上则四叶树是星形（不显示）。

## 文件

- `probe.py`：基础工具（解析、显示判定、实线分量、暴力 Δ）
- `probe3.py`：中位数-扇区规则与暴力对拍（`python3 probe3.py`）

## 对求解器的意义

这条规则把"放置 Δ"变成了**按物种树节点的三扇区聚合**，可以用导师的 13 状态 DP
（每种染色 O(1) 读根状态）在**一次 DFS** 里算出所有分支的 Δ —— 即 ASTRAL 式放置，
而不是每个候选重扫整棵树。

## 更新（第二轮验证）

1. **扇区规则**（probe3）与暴力在 20 组随机用例上一致；
2. **聚合公式**（probe4）：
   ```
   对每个内部节点 m（非根），三个扇区 S1,S2,S3：
     p 在 S1 → Δ += X(S1)·P(S2,S3)
     p 在 S2 → Δ += X(S2)·P(S1,S3)
     p 在 S3 → Δ += X(S3)·P(S1,S2)
   X(S)=|S∩C_x|（C_x 为 x 的实线连通分量），P(S,T)=S×T 间的实线对数
   ```
   与暴力在 9 个插入位置全部一致。
3. **重要修正**：计分是"每棵基因树分别计数再求和"，所以聚合公式必须对**每棵树**分别算。
   第一版 probe 在第一个满足的基因处 `break`，导致对拍不一致——问题在验证脚本，不在公式。
