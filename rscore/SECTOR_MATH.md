# 扇区（sector）方法：精确叶子放置曲面的数学推导

> 目标：给定二叉物种树 `S` 与一批多叉、带 S/D 边标号的基因树 `g`，
> **精确**求出"把叶子 `x` 重挂到任意位置"的得分变化面，并且
> (1) 计分严格等于比赛口径，(2) 时间/空间复杂度尽量低，(3) 天然可并行。
>
> 全部推导已通过数值对拍（见 §9，`sector_math_check.py`，5 个层级、239 组随机实例）。
> 文中公式一律用纯文本写，不使用 LaTeX。

---

## 0. 记号

| 记号 | 含义 |
|---|---|
| `S` | 物种树，**二叉无根**，叶 = 类群（taxon） |
| `x` | 被移动的叶子 |
| `S-` | `S` 删去 `x` 并抹去其父节点（2 度点）后的二叉无根树，叶数 n-1 |
| `pi` | `S-` 某条边的**内点**（唯一合法的挂载点，见 §1.3） |
| `g` | 一棵基因树（**多叉**），边分实线（solid）/ 虚线（dashed） |
| `A_u` | 从节点 `u` 出发**只走实线**可达的类群集合（"u 的实线可见集"） |
| `A_x` | `x` 的**实线块**：`x` 所在实线连通分支的类群集 |
| `C_j(q)` | 基因树节点 `q` 的第 `j` 个分量（删 `q` 后的一块）的类群集 |
| `i_q(x)` | 使 `x ∈ C_j(q)` 的那个下标 `j` |
| `D_1,D_2,D_3` | `S-` 内部节点 `m` 的三个分量（三分划），`dir_m(pi)` = 含 `pi` 的那个方向 |
| `Q_d(q,j)` | `= |D_d ∩ C_j(q) ∩ A_q|` |
| `P_d(q,i)` | `= |D_d ∩ C_i(q) ∩ A_x|` |

打分口径（`scorer/SPEC.md`，与暴力实现逐值对拍过的唯一权威）：

```
score(S) = SUM over genes g, SUM over quartets q (4 taxa of g)
             [ S displays q ]  *  [ q reliable in g ]
```

`q = ab|cd` 在 `g` 中**可靠** <=> 同时满足

* ② `g` **显示** `ab|cd`：存在一条边，一侧恰含 `{a,b}`、另一侧恰含 `{c,d}`；
* ③ 路径 `a->b` 与 `c->d` 上每条边都实线（叶子边恒为实线）。

① "`S` 显示 `q`" 由 `q` 在 `S` 中的拓扑自动给出。**注意 ② 是独立条件**，
不能被 ① 或 ③ 蕴含 —— 这正是旧"扇区公式"多算约 100 倍的根因（§10）。

## 1. 三条基本事实

### 1.1 可靠四叶树在基因树上被"恰好一次"计数

对固定的 4 个类群 `{x,a,b,c}`，设 `g` 显示 `xa|bc`。在 `g` 中考察所有节点 `q`，
把 4 个类群按 `q` 的分量归类。称 `q` 是一个 **2-1-1 节点**，若这 4 个类群
恰好占据 `q` 的 3 个分量（分布 2+1+1）。

* 4 个类群在 `g` 中的 Steiner 子树恰有 **2 个**内部节点 `p, q'`，都是 2-1-1 节点；
* `p` 是 `xa` 侧节点（`x,a` 在 **不同** 分量，`b,c` 在 **同一个** 分量）；
* `q'` 是 `bc` 侧节点（`x,a` 在 **同一个** 分量，`b,c` 在 **不同** 分量）。

于是：

```
   "x,a 同分量 且 b,c 分处两个不同分量"  的节点 q  <=>  q = q'   （唯一）
```

这就是"配对端 `{x,a}`"的计数节点。它同时保证了 ② （`q'` 处 `b,c` 分居两侧，
故 `q'` 两侧的边分离 `{x,a}` 与 `{b,c}`），并且 `q'` 是 `b->c` 路径上的节点。

### 1.2 实线条件可因子化

`q'` 处 `x,a` 同分量 => 路径 `x->a` 完全落在该分量内，不经过 `q'`；
`b,c` 分处两个分量 => 路径 `b->c` 必经 `q'`。因此

```
③  <=>  a ∈ A_x          (路径 x->a 全实线)
        且  b ∈ A_{q'},  c ∈ A_{q'}   (路径 b->q', q'->c 全实线)
```

两个条件互相独立、可分别计数 —— 这是后面所有公式能写成"乘积"的原因。

### 1.3 合法挂载点只有边的内点

把 `x` 挂到 `S-` 的节点 `m` 上会使 `deg(m)=4`，不是二叉。所以 `pi` 只能取
`S-` 的**边内点**（把该边细分出一个 3 度点再挂 `x`）。`S-` 有 `2(n-1)-3 = 2n-5` 条边。

## 2. 定理 1：叶子得分曲面可分解

### 2.1 陈述

固定 `S-`，则对任意 `pi ∈ int(edges(S-))`：

```
   Phi(S_pi)  =  Phi_0  +  SUM over internal nodes m of S- :   T_x(m, dir_m(pi))
```

其中 `Phi_0` 是**不含 x** 的四叶树贡献（与 `pi` 无关的常数），而

```
   T_x(m,d)  =  # { 可靠四叶树  x a | b c  :  a 落在 m 的第 d 个方向 }      (1)
             =  SUM over genes g :  T_g(m,d)
```

### 2.2 证明

只需证 `SUM_m T_x(m, dir_m(pi))` = "被 `S_pi` 显示且可靠的、含 `x` 的四叶树个数"。

`S_pi` 二叉，所以任何 4 个类群在 `S_pi` 中都有唯一拓扑。取一个含 `x` 的四叶树
`{x,a,b,c}`。在 `S-` 中取 `a,b,c` 的中位点 `m`（`m` 是唯一点，使 `a,b,c` 分处
`m` 的三个不同分量；`S-` 二叉保证这种点存在且唯一）。

设 `pi` 从 `m` 出发的方向为 `d`，则 `pi` 落在 `m` 通向某个方向 `d` 的弧上。
`x` 挂在 `pi` 处，故在 `S_pi` 的 Steiner 子树里：

* `a` 在方向 `d` 上 <=> `pi` 在 `m..a` 的弧上 <=> 四叶树拓扑为 `xa|bc`；
* 否则 `pi` 在 `m` 通向 `b` 或 `c` 的弧上，拓扑为 `xb|ac` 或 `xc|ab`。

（`S-` 二叉 => `m` 恰有 3 个方向，`pi` 必落在其中一条弧上，不会落到第 4 个方向。）

所以 `S_pi` 把 `{x,a,b,c}` 显示成 `xa|bc` **当且仅当** `a ∈ D_d`，`d = dir_m(pi)`。
把"所有含 `x` 的四叶树"按中位点 `m` 分组（唯一！），并对 `a` 的方向分类，即得 (1)。
`Phi_0` 补齐不含 `x` 的部分。证毕。

> 关键点：**分组是无重叠的**。每个含 `x` 的四叶树只有一个中位点 `m`，
> 且该 `m` 只有唯一一个 `a`（即拓扑里与 `x` 配对的那个类群）落在 `dir_m(pi)` 上。
> 因此 `SUM_m T_x(m, dir_m(pi))` 不会重复计数。

### 2.3 由定义 (1) 展开成可计算形式（核心公式）

对一棵基因树 `g`，用 §1.1 的唯一计数节点：

```
   T_g(m,d)  =  SUM over internal nodes q of g :

                  P_d(q, i_q(x))  *  CPS_d(q, i_q(x))                     (2)

   CPS_d(q,i) = SUM over unordered pairs {j,l},  j,l != i :
                  ( Q_{d'}(q,j) * Q_{d''}(q,l)  +  Q_{d'}(q,l) * Q_{d''}(q,j) )
```

其中 `d', d''` 是除 `d` 外的另两个方向。逐项对应：

| 公式中的量 | 保证的条件 |
|---|---|
| `P_d(q, i_q(x))` | `a` 与 `x` 同分量（②的结构）、`a ∈ A_x`（③配对侧）、`a` 在方向 `d` |
| `Q_{d'}(q,j)` | `b` 在方向 `d'`、在分量 `C_j`、`b ∈ A_q`（③单点侧） |
| `Q_{d''}(q,l)` | `c` 同理 |
| `j != l`, `j,l != i` | `b,c` 分处两个不同分量（②的结构） |

`{j,l}` 只取无序对，且 `Q_{d'}·Q_{d''}` 与 `Q_{d''}·Q_{d'}` 两项相加，
正好把"`b` 在 `d'` 方向、`c` 在 `d''` 方向"和"对调"两种有序分配各计一次 ——
由于每个类群只属于一个 `D_d`，同一四叶树不会被计两次。

### 2.4 一个有用的守恒律（自检用）

```
   SUM over d of T_g(m,d)  =  # (被 S_pi 显示、且可靠、配对端取 x 的) 四叶树        (3)
   SUM over m,d of T_g(m,d) =  # 含 x 的可靠四叶树（在 g 中）                       (4)
```

(4) 可用于任何实现的单元自检：把所有 `T_g` 加起来应等于"含 `x` 的可靠四叶树总数"。

### 2.5 与得分的关系

```
   Phi(S_pi) - Phi(S_pi')  =  SUM_m [ T_x(m, dir_m(pi)) - T_x(m, dir_m(pi')) ]    (5)
```

而 `dir_m(pi) != dir_m(pi')` **当且仅当 `m` 落在 `pi` 到 `pi'` 的路径上**
（`m` 在路径上 <=> `pi,pi'` 在 `m` 的不同分量 <=> 两方向不同）。故

```
   Delta(pi -> pi')  =  SUM over m on path(pi, pi') of
                          [ T_x(m, sigma_m) - T_x(m, tau_m) ]                   (6)
```

`sigma_m` = 朝 `pi'` 的方向，`tau_m` = 朝 `pi` 的方向。

## 3. 定理 2：物种树侧换根，O(n) 得到全部候选位置

固定参考位置 `pi0`，定义换根函数

```
   G_x(R)  =  SUM over internal m of S- :  T_x(m, par_R(m)),   R ∈ int(edges(S-))
```

`par_R(m)` = `m` 朝 `R` 的那个方向。由 (5)，`Delta(pi0 -> pi) = G_x(pi) - G_x(pi0)`。

**关键的局部性**：把 `R` 沿树移过内部节点 `m0` 时，所有 `m != m0` 的
`par_R(m)` **不变**（`m` 的两个方向只可能被 `pi,pi'` 分开，而这只发生在 `m` 本身）。
故

```
   G_x(R') = G_x(R) + [ T_x(m0, new_dir) - T_x(m0, old_dir) ]
```

于是：任取一条起始边算出 `G_x`，一次 DFS（每个节点 O(1)）即得**全部** `2n-5` 个
候选位置的 `Delta`。代价 `O(n)`。

**并行性**：这一步对每个 `x` 独立，`O(n)` 工作量，可按 `x` 完全并行，无共享写。

## 4. 定理 3：全部叶子一次扫完（复杂度主结果）

朴素做法：对每个 `x`，对每个 `m`，扫一遍所有基因树 => `O(n * K)` 每叶，
`K = SUM_g |g|`。全部 `n` 个叶子就是 `O(n^2 * K)`。

**本定理把它降到 `O(n * K)`（一次全量打分）**：对固定的 `m`，
`x |-> T_x(m,d)` 这整个数组可在一次基因树遍历里全部算出。

### 4.1 关键引理：P 只依赖 (分量, 实线块)

由 `P_d(q,i) = |D_d ∩ C_i(q) ∩ A_x|`，`x` 只通过 `A_x` 出现，而
`A_x = A_{x'}` 当 `x,x'` 在同一个实线块。故：

```
   引理 4.1  若 x, x' 落在 q 的同一个分量 且 在同一个实线块，
             则 P_d(q, i_q(x)) = P_d(q, i_q(x')).                        (7)
```

换句话说 `P_d(q,i)` 对该 (分量, 实线块) 组合内的所有 `x` 取**同一个值**，
从而可以与 `x` 无关地算出一个"边权"：

```
   EDG_d(q, i)  =  CPS_d(q, i) * P_d(q, i)        （对固定的实线块 gamma）   (8)
```

```
   T_x(m, d)  =  SUM over internal q of EDG_d(q, dir_q(x))      (x 属于 gamma) (9)
```

### 4.2 计算 (9) 的 O(|g|) 路径和

把 `g` 任意定根为 `r`，令 `par(u)` 为父节点。把 (9) 按 "`x` 是否在 `q` 的子树里" 拆开：

* `q` 在 `r -> x` 路径上：`dir_q(x)` = 朝 `x` 的那个孩子；
* `q` 不在该路径上（即 `x` 不在 `q` 的子树里）：`dir_q(x)` = `par(q)`。

记 `GP(q) = EDG_d(q, par(q))`（`q != r`），`TOTALP = SUM_{q != r} GP(q)`，则

```
   T_x(m,d) = TOTALP + SUM over edges (p -> u) on the r->x path of
                          [ EDG_d(p -> u) - GP(p) ]                          (10)
```

这是**边权差分**形式的路径和，一次 DFS 前缀累加即可对全部 `x` 同时求出（每个叶子 O(1)）。

> 这一步容易写错：曾误写成"每个路径节点加 `EDG(p->u) + EDG(u->p)`"，
> 多算了 `EDG(u->par)` 项 —— 对拍（§9 L5）立刻报错并暴露了这一点。
> 正确形式必须是**差分** (10)。

### 4.3 实线块的一般处理（保证任何基因都精确）

`P_d(q,i) = |D_d ∩ C_i ∩ gamma|` 依赖 `x` 的实线块 `gamma`。两种算法，取小者：

* **大块（gamma 很大，如 rep01 常见的 7800 叶）**：用补集
  ```
     P_d(q,i) = |D_d ∩ C_i| - |gamma^c ∩ D_d ∩ C_i|
  ```
  `gamma^c` 小（rep01 的基因树约 1150 个叶子）=> 每个 `(基因, m)` 多一遍
  只含 `gamma^c` 指示的计数即可，仍是 `O(|g|)`。

* **小块（|gamma| 很小，如 rep01 的基因 3 最大块仅 19 叶）**：直接枚举
  ```
     T_x(m,d) = SUM over a ∈ gamma ∩ D_d of
                  ( S_x(d) - PathSum_x(a, d) )
     S_x(d)      = SUM over q of CPS_d(q, i_q(x))              （(10) 取 EDG=CPS）
     PathSum_x(a,d) = SUM over q ∈ path(x,a) of CPS_d(q, i_q(x))
  ```
  `path(x,a)` 在同一实线块内，很短（或预先做一次前缀和即可 O(1) 查询）。

两条路都是 `O(|gamma|)` 或 `O(|g|)`，且 `SUM_gamma |gamma| = |g|`，
所以整体仍是 `O(|g|)` 每 (基因, m)。

## 5. 复杂度总账

记 `n` = 物种树叶数 = 10000，`K = SUM_g |g|` = 1000 x 11165 ≈ 1.1 x 10^7。

| 阶段 | 工作 | 次数 |
|---|---|---|
| 相位 1：对每个 `m`，对每个基因，算 `EDG` + 路径和 | `O(K)` | `n` 次 => `O(n K)` ≈ 1.1e11 |
| 相位 2：对每个 `x`，物种树侧换根（定理 2） | `O(n)` | `n` 次 => `O(n^2)` ≈ 1e8 |

```
   总计  =  O(n * K) + O(n^2)  ~=  1.1e11 次节点操作  =  一次全量打分的代价
   输出  =  n 个叶子 x (2n-5) 个位置的精确 Delta  (约 2e8 个值)
```

对比：

| 方案 | 全部叶子全部位置的精确 Delta |
|---|---|
| 逐叶朴素（placer2 / sector_run 的做法） | `O(n^2 K)` ≈ **1.1e15** |
| 本方案 | `O(n K)` ≈ **1.1e11**（**降 10000 倍**） |
| 单次 leaf-SPR（只试 1 个位置） | `O(K)` ≈ 1.1e7 |

也就是说：**一次全量打分的时间，换来"每个叶子各自的最优挂载位置"**。

空间：`T_x(m,d)` 共 `3 n n` 个值，需 `int64`（单个值可达 ~1e11）=> 2.4 GB，
在 240 GB 节点上完全可行；若要省内存可只存 `Delta` 差分或按 `x` 分块（代价是重扫）。

## 6. 并行方案（严格无冲突、结果可复现）

```
相位 1:  外层并行 = m  (10000 个任务, 每任务 O(K))
         每个任务写自己的一段 T[m][*,*]，分片互不重叠 => 无锁、无原子、无归约
         每线程 scratch = O(|g|)（逐基因处理，一个基因的计数数组约 9000 个 int）

相位 2:  外层并行 = x  (10000 个任务, 每任务 O(n))
         每个任务只读 T[*, x, *]、只写自己的答案

求和顺序:  全部整数运算 => 与线程数/调度无关，bit-identical 复现
```

用 224 线程时相位 1 受内存带宽限制，预期 ~1–2.5 分钟；相位 2 < 5 秒。

## 7. 为什么必须"精确"：定理 1 里的三个条件缺一不可

| 漏掉的条件 | 后果 |
|---|---|
| 漏 ②（g 显示） | 旧扇区公式 `X(S1)*P(S2,S3)`，在 rep01 上 997792 vs 真值 9411（**~100 倍过账**），只能当排序器 |
| 漏 ③（实线） | 把虚线路径当成可靠，分数虚高 |
| 漏 ①（S 显示） | 在二叉 `S` 上自动成立，但若中途用到非二叉的中间树就会错 |

用 (2) 式时三个条件分别由 `P/Q` 的集合交、`j != l` 约束、和 `dir_m(pi)` 分工保证。

## 8. 与 leaf-SPR 的关系

* leaf-SPR：`O(K)` 评测**一个**候选位置，精确；随机采样一个位置，接受则前进。
* 本方法：`O(nK)` 评测**全部** `n` 个叶子的**全部**位置，精确。
* 每单位时间的"精确 Delta 数"：leaf-SPR 约 `1/0.7s`；本方法约 `2e8 / 60s ≈ 3e6/s`，
  高出约 **2 x 10^6 倍**（因为共享了 `m` 这一维的遍历）。

## 9. 数值验证（`rscore/sector_math_check.py`）

5 个层级，全部为精确整数比对，随机实例覆盖：二叉物种树、**多叉**基因树、
虚线比例 0 / 0.2 / 0.3 / 0.45 / 0.5 / 0.6、缺类群 0 / 0.1 / 0.2 / 0.35、`n = 7..12`。

| 层级 | 检验内容 | 结果 |
|---|---|---|
| L0 | 逐四叶树暴力算 `Phi(S_pi)`（所有 `pi`） | 基准 |
| L1 | 按定义枚举 `(a,b,c)` 算 `T_x(m,d)` | 基准 |
| L2 | 定理 1 的分量公式 (2) | `L1 == L2` 全通过 |
| L3 | 定理 2：`Phi(S_pi) - Phi(S_pi0) == G(pi) - G(pi0)`，遍历**所有** `pi` | 全通过 |
| L4 | 引理 4.1：`P` 对 (分量, 实线块) 均匀 | 全通过 |
| L5 | 定理 3：一次扫算出**所有**叶子的 `T`，与 L2 逐叶相等 | 全通过 |

最终批量结果：**239/239 组全部通过**（配置 A n=8/g=3/dash.3 60 组，B 全实线 30 组，
C dash=.6/miss=.2 30 组，D n=10 25 组，E n=11/dash=.5 15 组，F n=12 10 组，
外加 dash=0/0.45/0.6、n=7/9、miss=.35 等 69 组）。

对拍过程中发现并修正了两个真实错误：

1. **`solid_visible_from` 漏判分量根边是否为实线** —— 会把虚线隔开的叶子算进 `A_q`；
2. **基因树路径和写成 `EDG(p->u) + EDG(u->p)`** —— 正确形式是差分 (10)。

另一个**不是**数学错误、但会毁掉结果的实现陷阱：
类群 id（taxon）与节点 id（node）必须严格分离；两者的混用会让 L1/L3 随机失败。

## 10. 旧"扇区公式"到底错在哪

旧公式 `X(S1) * P(S2,S3)`（每个节点、每个扇区一项）实际统计的是
"① 且 ③ 但**不含 ②**"的四叶树：它允许 `g` 根本没有解析出该四叶树
（例如 5035 度的星形节点里绝大多数孩子是单叶，`C(1,2)=0`，本不该贡献，
但旧公式仍按"任意两片在 S1、一片在 S2、一片在 S3"计数）。
rep01 的基因树多叉极重，所以过账达到约 100 倍。

修正方式就是 §1.1 的"唯一计数节点"：把计数锚定在 `q'`（`bc` 侧内部节点），
而不是锚定在"任意满足 2-1-1 的位置"。

## 11. 实测并行标度（sector_sweep.cpp，本机 16 核 / 32 SMT，L3 32 MB）

数据：rep01 的 1000 棵真实基因树（K = 1.1e7 节点）+ 真实的 10000 叶物种树，
每个配置处理 128 个 m。三种并行策略，16 次运行 **checksum 完全一致**（整数运算，可复现）：

| 线程 | `m`（任务=1 个 m） | `block` B=8（基因外层） | `nested`（基因并行+归约） |
|---|---|---|---|
| 1 | 50.84 s (397 ms/m) | 49.39 s | 52.04 s |
| 2 | 26.38 s | — | — |
| 4 | 13.99 s | 16.29 s | 13.94 s |
| 8 | 7.03 s | 9.19 s | 7.11 s |
| 16 | **4.20 s** (32.8 ms/m) | 7.01 s | 6.48 s |
| 32 | 5.23 s（SMT 回退） | 7.46 s | 6.62 s |

结论：

1. **纯 `m` 维并行最好**：16 核加速 12.1x（75% 效率），32 线程（SMT）反而回退 24%。
2. **加基因维并行是净亏**：16 线程时 6.48 s vs 4.20 s（**慢 1.54x**）。
   开销来自"每 m 一次"的 `T` 线程累积缓冲归约：`T x 3n x 8B` 的写+读，
   10000 个 m 累计约 38 GB 内存流量 + 4.8e9 次加法。**收益 < 开销，不采用。**
3. **`m` 分块（基因外层循环）单线程只快 3%**（49.4 vs 50.8 s）——因为基因树结构
   （约 200 KB/基因）远小于每 (m,基因) 的 scratch 数组（约 400 KB），局部性收益有限；
   且块粒度变粗后 16 线程时反而更慢。**不采用（或只用 B=2..4）。**

全量外推（10000 个 m）：本机 16 核约 5.5 min；集群 112 物理核按 75% 效率约 **45-60 s**。
加上相位 2（1e8 次操作，< 5 s）和 `T` 的 2.4 GB 落盘（约 2 s）：
**一轮 = 全部 10000 个叶子 × 20000 个位置的精确 Delta，约 1 分钟。**

对比 leaf-SPR：约 1.4 个精确位置/秒；本方案约 `2e8 / 60s = 3.3e6` 个精确 Delta/秒，
单位时间产出高约 **2.4e6 倍**。

### 11.1 实现中修掉的 3 个真 bug（都由对拍/一致性检查抓出）

| bug | 症状 | 定位方式 |
|---|---|---|
| 叶边实线标记被 `!kids.empty()` 挡住 | `cntS` 恒 0，全部输出 0 | 打印 `max|P|` |
| `compute_sdir` 的 `seen` 时间戳每次从 0 开始 | 从第 2 个 m 起 DFS 提前退出，结果随线程数漂移 | 1 vs 2 线程 checksum 不一致 |
| `nested` 策略的累积缓冲在 `omp parallel` 内声明 | 每个线程各有一份，归约只看到自己 | checksum 随线程数单调变大 |

### 11.2 尚未完成：多实线块的一般情形（route B）

当前 C++ 实现的是 **route A + 无条件修正项**：`P` 用"最大实线块"，
修正项 `T_x(m,c) -= S_x(m,c)` 对每个 `x` 都减。这只对 **`x` 落在最大实线块内**的叶子正确
（rep01 多数基因约 87% 的叶子）。对块外叶子会**过度扣除**（实测出现负值）。

价值交叉验证（`tools/sector_cmp_cpp*.py`，9 类群小实例）：

| 基因树 | 比对 | 结果 |
|---|---|---|
| 全实线（单一块，route A 精确） | C++ vs Python，54 个 (m,x) x 3 组 | **162/162 一致** |
| 30% 虚线（多块） | C++ vs Python | 不一致（28/54 等）→ 正是上面的缺口 |

修法（已论证，`O(|gamma|)` 或 `O(n_g)`，总量仍 `O(n_g)`）：对块外叶子改用 route B
`T_x(m,d) = SUM_{a in gamma_x ∩ D_d} ( S_x(m,d) - PathSum_x(a,d) )`，
其中 `S_x` 就是已有的 `accCPS`，`PathSum` 只需在**块内短路径**上求和
（需要把每个有向边的 `CPS` 值留下，约 528 KB/线程）。修正项同时改为"仅当 `x ∈ gamma` 时施加"。

### 12.1 交叉验证（`tools/sector_cmp_cpp.py`）

9 类群小实例，物种树/基因树同源生成，Python 侧用 §2.3 的公式逐四叶树独立计算：

### 12.2 已知的性能问题（下一步）

引入 route B 后单线程从 397 ms/m 涨到 754 ms/m，并且 16 线程的加速从 12.1x 掉到 4.8x。
已定位的组成（单线程）：
route B 本体约 +4%（`SUM_{非最大块} |gamma|^2` 在全部 1000 个基因上平均只有 6874，
最大 23461，所以 route B 的计算量很小）；
其余 +80% 与标度损失来自主循环里为 route B 新增的**每节点分支与冷写**

16 线程回到 117 ms/m（仍有 6.2x）。
下一步：把 CPS 值改为**按块内边紧凑存储**（每条块内边 2 个方向，总量约
`2 * SUM_gamma (|gamma|-1)`，只有几千个 int，可常驻 L1），彻底去掉主循环里的分支。

### 13.1 需要核对的一个矛盾

早前记录的 leaf-SPR 在 500 类群上从同一分数出发 6 轮 x1000 采样后达到
2,537,530,918（+4.9%）。但本轮精确曲面显示：从 2,418,965,337 出发
**只有 5 个叶子存在改进移动，且总共只能拿到 +0.155%**，之后即彻底收敛。
两者不可能同时成立 —— 要么当时 leaf-SPR 的起点/数据不同，要么它的接受判据
与实际分数口径不一致。这件事必须查清（它决定我们该往哪个方向继续投时间）。


### 13.3 关键反证：曲面在 500 类群上**不精确**（2026-11-16 发现）

从"扇区收敛"的树（2,422,715,072）继续跑 leaf-SPR：

```
./spr -s /tmp/nni500_best.tree -i results/baseline500_g.trees --rounds 3 --iters 300 --leaf 1
  round 1: accepted=12 gain=9,376,417
  round 2: accepted=13 gain=13,354,154
  round 3: accepted=11 gain=14,046,178
  final = 2,459,491,821     (+36,776,749, +1.52%)
```

**36 个单叶移动被接受，而扇区方法刚刚"证明"没有单叶移动能改进** —— 直接矛盾。
所以 500 类群规模上相位 1/2 的曲面是**错的**（小实例 9 类群的对拍全部通过，
说明 bug 只在更大规模/不同实线块结构下暴露）。

最可能的定位：**route B（块外叶子）在大规模上算错**。理由：
(1) 排第一的移动单独应用后预测与实际**逐位相等**（+3,581,846），
说明 route A（最大块内叶子）与相位 2 的换根是对的；
(2) 只有 5 个叶子报出改进 —— 与"只有 route A 的叶子算对了"的现象一致；
(3) route B 只在 9 类群实例上验证过，其 `cpsUp/cpsDown` 按槽位索引在大规模下
很可能还有陈旧读或越界（槽位是每基因重新编号的）。

**在修好之前，§13 的 +0.155% 不能作为扇区方法的效果**。
下一步诊断（顺序）：
1. 在 500 类群实例上取一个块外叶子，用权威评分逐位置暴力核对 `Delta`（几次 1 s 的评分即可）；
2. 若确实错，去掉 route B、只保留"最大块内叶子"（约占 87%），
   重新跑并再次用 leaf-SPR 反证；
3. 修好后重跑 §13 的流程。


### 13.4 定量诊断：route B 确实算错了

在 `/tmp/nni500_best.tree`（权威分 2,422,715,072）上，用 `--leaf L` 单独探测每个叶子的
"最佳位置"及其预测 `Delta`，再**实际应用**并用权威评分核对：

| 叶子 | 预测 Delta | 实际 Delta | 结论 |
|---|---|---|---|
| 3050 | 0 | 0 | ✅ |
| 100 | **-53** | **-430,223** | ❌ 差 8,000 倍 |
| 6763 | **-26,870** | **-3,606,330** | ❌ 差 134 倍 |

而在**前一轮**（同一个叶子 6763、不同的树）它的最佳移动预测 +3,581,846 与实际**逐位相等**。

把两件事放在一起：`Delta` 算对的时候都是"该叶子在最大实线块内"（route A），
算错的时候（100、6763 在当前树上）都是 route B；且报出的量级系统性偏小
（-53 对 -430,223）—— 正是"块外叶子的配对侧被按最大块计数"的症状。

**结论：route A（最大块内叶子，约 87%）与相位 2 的换根是精确的；route B 是错的。**
这意味着：

* §13 的 +0.155% 与"收敛"都**不可信**（几乎全部改进机会都在 route B 的叶子上）；
* 但 route A 的部分仍然可用：只对"落在最大块内"的叶子出移动，就是精确的
  （这部分叶子占多数，且每次都能拿到该叶的**全局最优**位置）。

## 16. 关键反证：定理 2 本身不成立（2026-11-17 凌晨，自主测试得到）

有了逐位置地面真值（`sector_exact`，已与官方 `ref_brute` 在 8 例 x 9 叶上 72/72 一致）
之后，做了一次干净的隔离实验（20 类群实例 `m20_dom_1`，叶子 0，真实存在的边 (12,14)）：

| 量 | 值 |
|---|---|
| 真值（`sector_exact` 逐位置重算）| **+32** |
| 由 **定义式** 的 `T_direct` 算出的 `SUM_m [T(m,dir(R)) - T(m,dir(R0))]`（D 集合含 x）| 113 |
| 同上（D 集合去掉 x）| 154 |
| 由**分量公式** `T_formula` 算出的同一量（= C++ 快表面）| 154 |

也就是说：**即使 `T` 完全按定义计算，`Delta = SUM_m [T(m,dir_m(R)) - T(m,dir_m(R0))]` 也不等于真实分差**
（113 / 154 vs 32）。而 `T` 与定义的一致性、以及 `T_formula` 与 C++ 的一致性，此前都已逐值验证过。

### 16.1 结论

1. **定理 2（换根/路径和）的推导有错**，不是实现问题。route A / route B / `placedelta` 全都建立在
   同一套推导上，所以它们的 `Delta` 系统性偏大 —— 这与所有观察吻合：
   `placer2` 会让树变差、500 类群时"扇区收敛"却能继续被 leaf-SPR 改进、route B "验证通过"但流水线不对。
2. 因此**"快表面 + 精确复核"这条路线目前不可用**：排序器本身可能是错的。
3. **可用的东西**：
   * `sector_exact`（逐位置真重算，与官方口径 72/72 一致）—— 正确的 sector ✅
   * 官方 `ref_brute`、`score_fast`（在干净输入上一致）✅
   * 干净的对抗语料 + 生成器 + 对拍脚本（`tools/adv_gen.py`、`adv_cases/`）✅

## 17. 修复完成：快扇区在 20/30/50 类群上 **300/300 精确**（2026-11-17 凌晨）

### 17.1 根因（一句话）

`sector_place` 里把"位置 → 方向"的映射写成了**判断 u/v 是否为 m 的邻居**，
而不是**u/v 落在 m 的哪个分量**。于是除极少数 m 外全部返回 -1 被跳过，
基准值 `G0` 少算一大块 → 所有 `Delta` 系统性偏大。这一处同时解释了
"`placer2` 会把树改差"、"扇区收敛后 leaf-SPR 还能改 1.5%"、以及两次自相矛盾的结论。

第二个 bug：换根的起点选在 `(p, ab[0])`，而 `ab[0]` 常常是**叶子**（x 的兄弟），
所以 BFS 的第一步就 `continue` 死掉（实测 `G filled 1/74, bfs=1`）。
修法：起点双向入队；跨过 `p` 时不贡献（`p` 不在 m 集合里）。

### 17.3 结论

* **快扇区（`sector_sweep` + `sector_place`）现在是精确的**，
  在 9 / 20 / 30 / 50 类群、包含全部踩坑结构（无主导块、单叉、大星形多叉、深毛毛虫、大量缺类群、全实线）上都与逐位置真值一致。
* 复杂度仍是 `O(nK)`（相位 1）+ `O(n)`/叶（相位 2 换根），全量可行性不变。
* `sector_exact` 保留为**独立裁判**（慢，`O(#位置 × K)`/叶），只用于验证。

### 17.4 写下来的两条教训

1. **对拍必须两侧用同一棵树、同一套编号**。`detach()` 会重编号，我把 `S` 与 `S-`
   混用过两次，造成两个完全错误的"定理被推翻"结论。
2. **"位置→方向"这类索引映射必须单独验证**。它错了不会崩，只会让数字系统性偏一点，
   而偏一点在局部搜索里等于把方向搞错。

### 17.6 仍待修的一处（应用移动后建树）

`sector_place --apply N --out` 在**同时应用多个移动**后输出的 newick 会出现
"node with 3 children"（某处度变成 4），`score_fast` 拒绝。原因：多个移动在**同一快照**
上评估，后一个的目标边可能已被前一个改掉（已用 `S.pos(u,v)<0` 跳过，但仍有个别情况漏过）。
修法：应用后校验每个节点的度数，或改为**一次只应用一个移动并重新评估**。

## 15. 落地清单（按依赖顺序）

1. `T` 的契约：`int64`，`(m, d)` 索引，按 `x` 分片（相位 2 友好）；
2. 每个 `(基因, m)` 需要的前置：每个叶子的"物种方向编号" `sdir[taxon]`（一次 `O(n)` 全 `m` 可复用）；
3. `CPS` 用 O(1) 公式：`CPS_d(q,i) = TA*TB - SUM_{j != i} Q_{d'}(q,j) Q_{d''}(q,j)`，
   其中 `TA = SUM_{j != i} Q_{d'}(q,j)`、`TB = SUM_{j != i} Q_{d''}(q,j)`；
4. `GP`/`TOTALP`/前缀和在基因树上一次 DFS；
5. 自检：随机抽 `x`，用 (4) 校验 `SUM_{m,d} T_g = 含 x 的可靠四叶树数`。
