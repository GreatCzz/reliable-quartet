# 可靠四叶树打分器：公式与实现说明

> 目标：给定一棵**二叉**物种树 S 与一批（多叉、带 S/D 边标号的）基因树，快速算
> `score(S) = Σ_g #(S 显示、且在 g 中可靠的四叶树)`。

## 1. 定义

- 基因树 g 可多叉；内部边标 `S`（实线）或 `D`（虚线）；**叶子边无标号，视为实线**。
- 四叶树 `ab|cd` 在 g 中**可靠** ⟺ 路径 `a→b`、`c→d` 上的每条边都实线
  （等价于 `LCA(a,b)`、`LCA(c,d)` 到四个叶子的四条末端枝全实线；锚点之间那条路可以是虚线）。
- `ab|cd` 在 g 中**显示** ⟺ 存在一条边，它的一侧恰含 `{a,b}`、另一侧恰含 `{c,d}`。

## 2. 显示判据（关键，曾经写错）

设 `u = LCA(a,b)`，`v = LCA(c,d)`，`su / sv` 为 u/v 的子树叶子集。则

```
ab|cd 显示  ⟺  (c ∉ su 且 d ∉ su)  或  (a ∉ sv 且 b ∉ sv)
```

- 直观：要么 u 的子树把 a,b 整个包住、不碰 c,d（取"u 上方的边"）；
  要么 v 的子树把 c,d 包住、不碰 a,b（取"v 上方的边"）。
- `u = v` 时两个条件都不成立 → 必不显示（星形/多叉处不会凭空产生四叶树）。
- 已验证：2000 棵随机多叉树上**所有四叶树**，与"逐边扫描"的暴力判据完全一致。

> 早期错误版本用的是"祖先关系 + 叶子落在通往对方的那个孩子里"，会把
> `u` 的子树恰好等于 `{a,b}`（边在 u 上方）这类显示情形误判为不显示。

## 3. 计分公式

四叶树在 S 的 `LCA` 处 2-2 分家，且该节点唯一，所以

```
score = Σ_{v ∈ S 内部节点} F(l_v, r_v)
```

对某个簇 X（S 的某个子树叶子集），在基因树 g 上自底向上聚合：

| 量 | 定义 |
|---|---|
| `cnt[u]` | 从 u 出发沿实线可达、且属于 X 的叶子数 |
| `C(u)` | `Σ_{孩子 c} [边 u→c 实线] · cnt[c]` |
| `anc[u]` | `Σ_{i<j} cnt[c_i]·cnt[c_j]`（以 u 为锚点的实线成对数；**只算跨孩子**） |
| `cum[u]` | `anc[u] + Σ_{孩子} cum[c]`（子树内实线成对总数） |
| `G[u]` | `(C(parent) − cnt[u]) + G[parent]`；若父边为 D 则 `0`（路径断掉） |
| `H[u]` | `cnt[u] · G[u]` |

则

```
F(l,r) = cum_l(root)·cum_r(root)      # 所有实线成对组合
       − Σ_u anc_l(u)·anc_r(u)        # 两个锚点重合 → 必不显示
       − Σ_v anc_r(v)·H_l(v)          # u 是 v 的真祖先，且 l 的成对有一片落在 subtree(v)
       − Σ_u anc_l(u)·H_r(u)          # 对称
```

**第二处曾写错的地方**：`H` 原先写成 `cnt·(C(w) − cnt)`，实际必须是
`cnt·(C(w) − cnt[ch(w→v)])`。反例：某个祖先节点只有一个"实线孩子"时，
`C(w) = cnt` 会让"同一孩子内部的两片叶子"被误当成"跨孩子的成对"。

## 4. 复杂度

对 S 的每个内部节点、每棵基因树，两次 O(n) 扫描（n = 基因树节点数）：

```
总工作量 = O(m · n · T)      m=|S 内部节点|, n=|g|, T=基因树数
```

本数据 m≈10⁴、n≈9×10³、T=1000 → 约 9×10¹⁰ 次节点操作。
Python 实测：200 类群 / 20 棵树 = 0.7 s（35 ms/树对），按 m·n 外推全量约 10 小时；
C++ 单线程预计 ~10 分钟，32 线程 ~20–40 秒。

可做的剪枝：`cum_l` 或 `cum_r` 为 0 的 S 节点直接跳过；`anc` 全 0 的基因树节点跳过。
