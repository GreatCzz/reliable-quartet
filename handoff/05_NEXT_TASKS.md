# 下一步任务（按优先级）

## T1（首要）把增量 13 状态 DP 接进我们自己的 NNI
**输入**：`rscore/solver/incr_dp.cpp`（已验证的原型）、`solver.cpp`（现有 NNI）。

**做法**：
1. 在 solver 里为每棵基因树构建二叉 resolve 版本（Huffman + C 边）并维护 V1/V2；
2. NNI 候选评估：只对 u、v 两个三划分重染变化的叶子，读根状态；
3. **逐值对拍**：同一棵树、同一步移动，新旧实现的 Δ 必须完全一致；
4. 1000 类群基准：记录单轮时间与总时间。

**验收**：
- 对拍 0 不一致；
- 1000 类群单轮 **≥5× 加速**（目标 10–50×）；
- 分数与旧实现相同（同一棵树、同样的 sweeps）。

**止损**：若 2 天内无法做到逐值一致，或加速 <2×，停止并记录原因。

## T2 用"好构造 + 我们的 NNI"跑全量
1. 构造：ASTER 框架放置（基因子集 100–200 棵）或 ASTRAL-IV（先 splice）；
2. 精修：T1 完成后的 NNI；
3. 评分：`score_fast`；
4. 目标：≥ 1.73e15；达不到则记录对照。

## T3 多起点 + 重组（在 T1 之后）
- 3–5 个不同构造的树（框架/共识/builder 多 seed）→ 各自 NNI → `recombine` → NNI；
- 预期 +0.1–1%，成本低。
