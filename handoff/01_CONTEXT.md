# 问题定义与计分口径（已确认）

## 目标

给定 1000 棵**多叉**基因树（每棵 9000 类群，并集 10000；内部边标 `S`/`D`，叶子边视为实线），
构造一棵 **10000 叶二叉物种树 S**，最大化：

```
score(S) = Σ_g # { 四叶树 q : q 被 S 显示，且在 g 中"可靠" }
```

- **显示**：存在一条边，一侧恰含 `{a,b}`、另一侧恰含 `{c,d}`；
- **可靠**：路径 a→b 与 c→d 全为实线（叶子边算实线；两锚点之间的路径可以是虚线）；
- **四叶树是无根的**：分数必须与根位置无关（根重挂不变性是硬性回归测试）。

## 计分公式（权威实现见 `scorer/`）

对物种树每个内部节点 v，孩子簇 A、B，其余 C：

```
W(A,B,C) = F(A,B∪C) + F(B,A∪C) + F(C,A∪B) − 2·(F(A,B)+F(A,C)+F(B,C))
score    = Σ_v W_v / 2   （再对所有基因树求和）
```

`F(X,Y)` = 2 片在 X、2 片在 Y，且被基因树显示、可靠的 四叶树数（两趟 O(n) DP）。

## 历史坑（必读）

1. **2026-10 的 P0**：旧实现只数"rooted LCA 处 2-2 分家"，漏掉 3-1 情形的四叶树，
   且分数随根重挂变化——已修为上面的三分划公式；
2. 由此推论：**任何"2-2 支持度"分解都不能用于我们的目标**（框架 NNI 因此不可用）；
3. 多叉基因树**不能**简单 resolve 后用 2-2 计数（会多算）；正确做法是
   "Huffman resolve + 合成边 C + 两套 DP 相减"（导师 `solution_fast.cpp` 的做法，已验证）；
4. 单叉节点、缺类群、CRLF 行尾都会让第三方工具崩或算错（详见 `08_LESSONS.md`）。
