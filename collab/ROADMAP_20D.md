## 2. 双轨闭环架构

### 轨道 A —— 盆地榨干器

```
统一批量 spr44（\|X\|≥2 子树） + 单叶 sector（\|X\|=1） + 定期 nni_incr 扫尾
```

- **一次 `sector_sweep` 的 T 表同时服务两类移动**（不再浪费另一半）；
- 按 `2Δ` 降序做**严格节点不相交打包**（数学保证兑现率 1.000000 ✓ 已被 8011 验证）；
- 每轮用 `fastscore` 5 秒复验（红线）。
- **定位**：给任何一棵有潜力的新树，2–3 小时内压到该盆地的局部极限。

### 轨道 B —— 跨盆地破壁器

```
① 多源造异盆地树
   a) 基因树随机 50%–70% 子采样（或按实连通分量信息量分组）
      → aster2 / stepwise 构造 15–20 棵骨架天然不同的初始树
      → 回全量数据跑几轮 nni_incr + 批量 spr44 恢复
   b) 从当前最优树出发，专挑低支持/高冲突边做 20–50 次大尺度随机子树重挂
      → 强行跳盆地 → 再爬到新的局部极值
② 全局重组吸纳
   历史 16 棵存档 + 轨道 A 产物 + 轨道 B 产出的 20–30 棵异盆地局部最优
   → 全部提取二分划 → recombine.cpp 精确三分划 DP（输出 ≥ 所有输入最大值）
③ 螺旋回流
   重组出新高分树 → 立刻回轨道 A 精修 → 精修结果再回灌二分划池
```

**判据**：轨道 A 在当前盆地预计再吃 **+0.05% ~ +0.10%**；
剩下 **0.18% ~ 0.23%** 若存在，只能靠轨道 B 的宏观骨架差异 ✗ 局部搜索无法到达。
